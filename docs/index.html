Live appCode

Drop a zip, see the robot. A six-joint arm loaded from a zipped ROS package, with a slider per joint.

Overview

Checking a robot description normally means installing ROS, sourcing a workspace, launching robot_state_publisher and opening RViz. URDF Viewer Online removes all of that: drop a zipped ROS package or a whole workspace into the browser and inspect the robot in 3-D, with a slider for every movable joint. Everything runs client-side with WebGL, so no files are uploaded.

Open the viewer

Features

  • Packages and workspaces. Accepts a zip of one ROS package or a workspace with many; package.xml files are discovered so package:// and $(find …) references resolve as they do under ROS.
  • xacro in the browser. xacro files are expanded client-side; plain URDF works too.
  • Meshes. STL, DAE, OBJ, glTF and GLB visual meshes.
  • Joints. A slider for every revolute, continuous and prismatic joint, with the URDF limits enforced.
  • Axis gizmo. Robot-attached X/Y/Z axes make flipped or mirrored joint axes easy to spot.
  • Static deployment. A static Next.js build that runs on any static host.

Built With

Next.js, React and TypeScript; three.js for rendering; urdf-loader and xacro-parser by Garrett Johnson; JSZip for the in-memory file system.
